# 在 DSH 设置里登录 Google Antigravity

在已经打开的独立 DSH 试用窗口，进入 **设置 → 模型**，找到 **Gemini（Google Antigravity）**。点击 **使用 Google 登录**，在官方 agy 打开的浏览器中完成 Google 授权，再回到 DSH。无需打开终端，也不用在 DSH 粘贴密码、验证码或 Token。

卡片显示 **已连接官方 agy** 后，关闭设置即可在当前会话的原生模型菜单里选择 Antigravity。切换模型不弹确认框，不另开 DSH 会话。登录不会替你发聊天消息。日用 Desktop 保持原样，那里 0.2.8 的旧 Gemini 登录入口不参与本次试用。

## 登录会做什么

- 打开试用页时，Host 用签名版 `agy` 1.5.12 查询它支持的登录方式，随后关闭进程。模型页只读取试用连接状态；不会打开 Google、创建官方会话或发送提示。
- 点击按钮后，Host 启动新的官方客户端，再次核对它提供个人 Google 登录方式，才发送 `authenticate(oauth-personal)`。官方程序负责打开浏览器和保存登录；按 [Google 的说明](https://antigravity.google/docs/install.md)，同一 Windows 用户下的其他 Antigravity 应用可能共用这次登录。
- 官方登录成功后，Host 关闭登录进程，另开一个空的官方会话获取真实模型列表，关闭探测进程，然后把模型挂到 DSH 的原生菜单。不会自动选模型、调用计费 API 或发送第一条消息。
- 等待期间可以点 **取消登录**。关闭设置只会停止这个卡片的轮询；回到设置可以继续看状态。取消等待不会退出 Google 账号或清除 Windows 登录。超时后可以手动重新检查状态。

## 试用范围

试用使用本机随机端口、独立的 DSH 数据目录和空工作区；不安装或替换日用插件，不导入日用账号。仅开放纯文本。专用 agy 设置拒绝文件读写、命令、网页和 MCP 操作，额外的 ACP 工具审批请求一律取消。这里没有验证 Windows 能阻止进程的全部文件或网络访问。

试用监听最多保留两小时。停止后保留试用会话和官方登录。带 DSH 本机访问凭据的启动地址只在浏览器交接时使用，不要分享运行目录里的交接文件。
